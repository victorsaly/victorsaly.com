# Share card

`npm run og` draws `public/og.png`, the picture a link to victorsaly.com shows when it is shared: 1200×630,
in the same layout as blog.victorsaly.com's own card, so the two read as one author.

`portrait.png` is the blog's home-page portrait print, copied from
`agentic-blog/site/src/assets/home/victor-portrait.png`. It was drawn as a linocut with OpenAI's image
model from Victor's reference photo and reviewed by Claude; the prompt is in that repo's
`site/src/assets/home/prompts.md`.
